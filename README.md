# Global Imports Analysis Dashboard

## Executive Summary

This project presents a professional **Global Imports Analysis Dashboard** developed in **Power BI** to analyze international import trends, trade growth, economic development status, and country-level import performance from 1974–2024.

The dashboard transforms raw global trade data into meaningful business intelligence insights, enabling users to monitor:

* Global import growth trends
* Regional trade distribution
* Economic development comparisons
* Country import rankings
* Income group analysis
* Long-term international trade patterns

The solution was designed to simulate a real-world economic analytics and trade intelligence reporting system.

---

# Business Problem

Understanding global trade trends is essential for:

* Economic policy analysis
* International business strategy
* Trade forecasting
* Market expansion planning
* Investment research

However, large-scale trade datasets are difficult to interpret without centralized analytics and visual reporting.

This dashboard solves that challenge by providing interactive and executive-level import analytics.

# Dataset Information

The dataset contains global import data including:

| Column             | Description                     |
| ------------------ | ------------------------------- |
| Country            | Country name                    |
| Continent          | Geographic continent            |
| Year               | Observation year                |
| Imports            | Total imports                   |
| Income_Group       | Economic income classification  |
| Development_Status | Developed or developing economy |
| CAGR               | Compound annual growth rate     |
| Trade_Value        | Import trade value              |

# Key Insights

Some important insights generated from the dashboard include:

* Europe contributes the highest total imports globally.
* Global imports have experienced strong long-term growth since 1974.
* Developed economies account for the majority of international imports.
* High-income countries dominate global trade volumes.
* Trade growth accelerated significantly after the 2000s.
* The United States and China remain leading import economies.
